# Models used by `eval_toolkit` (all run locally; recorded 2026-11-03)

No audio is sent to any external service. Network was used only to download the weights/code below and, for the TTS source set, to send the five sentence texts to the edge-tts service.
Caches: `~/.cache/pkv_models/` (HF hub cache `hf/hub`, torch.hub `torch_hub/hub`, AASIST code+weights `aasist_src/aasist`, ECAPA `ecapa`), except Whisper large-v3, which was already present in `~/.cache/huggingface/hub` and is loaded from there at a pinned revision (not re-downloaded).
Software: venv `~/venvs/pkv` (system site packages of miniconda `py311`): torch 2.11.0+cu130, torchaudio 2.11.0, transformers 5.2.0, speechbrain 1.1.1, scikit-learn 1.6.1, edge-tts 7.3.1. No extra packages had to be installed.
